# Game Assets

Drop new art for Sword Fighter 2 into these folders.

## Sunnyside pack layout

```
assets/sunnyside/
  characters/   animated human/goblin sheets or individual frames
  tiles/        tileset PNGs
  ui/           menus, buttons, icons
  crops/        farm / plant sprites
```

Put files in the matching folder. The game does not load these yet — this is the ready place to store them until they get wired in.
